# Project Plan	#
The objective of our project is to pull datasets from Spotify using the Spotify API, load it into a data warehouse, and perform basic analysis. 

## Consumers
The users of our dataset will be the data analytics team.

## Questions
* What is the average number of tracks on an album?
* What is the top 5 popular tracks in an album?
* What is the top 5 popular tracks in a genre?
* What is the average length of a song? What genres have the shortest average length? Longest average length?
* What is the most popular song by year? By decade?

## Source
Dataset	Spotify API(REST API)
